# weldjson

Weld digests and json fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/weldjson/

## Install / run

```bash
git clone https://github.com/theworker02/weldjson.git
cd weldjson
node src/cli.js
node --test
```
